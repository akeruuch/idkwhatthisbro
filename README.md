# Тепло

**Тепло** — учебный одностраничный сайт молодёжного пространства. Посетитель может посмотреть пример афиши, выбрать интересующие события, изучить галерею и оставить демонстрационную заявку или сообщение. Проект создан для практических занятий по веб-разработке, Git и GitHub.

## Основные возможности

- Переход между разделами страницы: «О пространстве», «Афиша», «Галерея», «Мои проекты» и «Контакты».
- Поиск событий и фильтрация по категории, стоимости и формату участия.
- Просмотр фотографий галереи в увеличенном виде.
- Адаптивное оформление и меню для небольших экранов.
- Сохранение выбранного формата афиши на устройстве пользователя.
- Демонстрационные формы заявки и обратной связи.

**Важно:** афиша содержит примерные события. Формы не отправляют данные организатору или на сервер: заявка и сообщение сохраняются только в `localStorage` текущего браузера.

## Используемые технологии

- **HTML5** — структура страницы и формы.
- **CSS3** — оформление, адаптивная сетка и анимации.
- **JavaScript** — фильтры, поиск, диалоговые окна и локальное сохранение данных.
- **Git и GitHub** — хранение проекта и истории изменений.

## Запуск проекта

1. Клонируйте [репозиторий проекта](https://github.com/akeruuch/idkwhatthisbro):

   ```bash
   git clone https://github.com/akeruuch/idkwhatthisbro.git
   ```

2. Перейдите в папку проекта:

   ```bash
   cd idkwhatthisbro
   ```

3. Откройте `index.html` в браузере. Для просмотра сайта не требуется установка зависимостей или запуск сервера.

## Как проверить работу

1. Откройте раздел «Афиша» и выберите категорию либо введите слово в строку поиска.
2. Измените параметры «Только бесплатно» и «Твой формат». Обновите страницу и проверьте сохранение выбора.
3. Откройте фотографию в галерее.
4. Заполните демонстрационную форму, учитывая, что данные остаются в браузере.
